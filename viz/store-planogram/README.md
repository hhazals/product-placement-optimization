# Store Planogram Viz

React + Vite app that renders the optimized fixture/lot assignment as an
interactive store grid → fixture planogram → item detail drill-down.

## Data flow

Reads `public/data/assignment.json` at **runtime** via `fetch()` (not bundled
at build time). That file is generated by the final cell of
`notebooks/04_cp_sat_assignment` — rerun that cell and reload the page to see
a new solve, no rebuild required in `npm run dev`.

Schema:

```json
{
  "N_I": 45, "N_J": 12,
  "grid": [[0, 2, 1, ...], ...],
  "fixtures": [
    {
      "A_ij": "A(1,11)", "A_i": 1, "A_j": 11,
      "fixture_type": "wall_hanger_small", "fix_idx": 0,
      "max_r": 3, "max_c": 7,
      "lots": [
        { "lot_ID": 1, "r": 1, "c": 1, "mode": "normal", "ItemOption": "nd388",
          "category": "ÇİZME", "ColorGroup": "navy blue",
          "saleability_score": 0.0245, "L_type_score": 0.468,
          "LifeStyleGroup": "Ayakkabı ST", "base_price": 7999.0,
          "discount_rate": 0.77, "effective_price": 1839.77 }
      ]
    }
  ]
}
```

## Commands

```bash
npm install
npm run dev      # local dev server, http://localhost:5173
npm run build    # static bundle -> dist/
npm run preview  # serve the production build locally
```
